Site Black Myth Wukong

Projeto desenvolvido como atividade acadêmica da disciplina de Desenvolvimento Web na Fatec, utilizando HTML, CSS e JavaScript.
O site apresenta informações sobre o jogo Black Myth: Wukong, sua história, personagens e elementos da mitologia chinesa, utilizando uma identidade visual inspirada na estética do próprio jogo.

Tecnologias utilizadas

CSS HTML JavaScript

Links

GitHub Repository Site online

Descrição

Site temático desenvolvido com HTML, CSS e JavaScript, inspirado no universo de Black Myth: Wukong e na mitologia chinesa que serve de base para o jogo.
O projeto apresenta informações sobre a história do Rei Macaco, Jornada ao Oeste, personagens e criaturas do universo do jogo, combinando conteúdo informativo com uma interface visual inspirada na estética oriental e na identidade visual de Black Myth: Wukong.
O desenvolvimento também envolveu a criação de um sistema de navegação interativo entre diferentes seções, utilização de elementos multimídia, personalização de fundos e organização de conteúdos em diferentes páginas.

Funcionalidades

  • Apresentação do jogo Black Myth: Wukong.
  • Trailer oficial integrado à página
  • Seção dedicada à história do Rei Macaco.
  • Conteúdo sobre Jornada ao Oeste e sua relação com o jogo.
  • Seção de personagens do universo do jogo.
  • Seção sobre os Yaoguai e a mitologia chinesa.
  • Menu de navegação lateral interativo
  • Navegação dinâmica entre seções utilizando JavaScript
  • Imagens e fundos temáticos para diferentes seções
  • Interface inspirada na identidade visual de Black Myth: Wukong
  • Estrutura organizada para diferentes tamanhos de tela
  • Navegação entre páginas e seções específicas do site
  • Footer com informações e links para redes sociais

Objetivo do projeto

Criar um site temático sobre Black Myth: Wukong, aplicando conceitos de HTML, CSS e JavaScript na construção de uma interface interativa e visualmente inspirada no universo do jogo.
