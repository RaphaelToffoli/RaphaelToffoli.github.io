Fichário de tarefas online

Um sistema de gerenciamento de tarefas (To-Do List) web desenvolvido em PHP e CSS3, com design conceitual inspirado em fichários e papéis vintage. O projeto permite organizar a rotina diária através de um fluxo completo de criação, categorização, arquivamento e lixeira.

Tecnologias utilizadas

PHP CSS HTML JavaScript

Links

GitHub Repositoty

Descrição

Aplicação de gerenciamento de tarefas desenvolvida para aprofundar o domínio em manipulação de arrays e lógica de CRUD em PHP nativo. O sistema utiliza sessões para gerenciar pendências, categorias, histórico de conclusões e lixeira, combinando lógica de backend com uma interface temática inspirada em fichários vintage.

Funcionalidades

  • Criação de tarefas com limite de caracteres, categoria e prioridade.
  • Edição de tarefas existentes diretamente na interface
  • Prevenção contra tarefas duplicadas ou em branco.
  • Criação dinâmica de novas categorias mantidas na sessão.
  • Marcação de tarefas concluídas com registro automático de data e hora (d/m/Y H:i).
  • Destaque visual com estampa/carimbo inclinado e texto riscado.
